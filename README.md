# Career Sheet A4 Prototype

ジュニアエンジニア向けの職務経歴書作成プロトタイプです。

経歴メモを貼ると、5W1H、誰主導、規模感、役割、数字、工夫の不足を診断し、追加質問を通じてA4一枚の職務経歴書に整理する体験を確認できます。

## 現在できること

- 経歴メモ入力
- 無料診断の表示
- 追加質問の表示
- A4一枚職務経歴書のサンプル出力
- コピー
- ブラウザの印刷機能によるPDF出力

## まだ未実装のもの

## レビューしてほしい観点

- 初見で「何をするサービスか」が伝わるか
- 無料診断と有料出力の境目が自然か
- ジュニアエンジニア向けの課題設定が刺さりそうか
- 入力から出力までの流れが分かりやすいか
- 500円 / 5回出力の価格感に違和感がないか

## ローカルでの確認方法

このプロトタイプは静的HTML/CSS/JSだけで動きます。

```powershell
python -m http.server 4173
```

ブラウザで以下を開きます。

```text
http://127.0.0.1:4173/
```

## 主なファイル

- `index.html`: プロトタイプ画面
- `styles.css`: デザイン
- `app.js`: 画面遷移とサンプルデータ
- `app_flow_spec.md`: アプリ仕様メモ
- `prompts_diagnosis.md`: 無料診断用プロンプト
- `prompts_a4_resume_generation.md`: A4出力用プロンプト
- `junior_engineer_resume_template.md`: 職務経歴書テンプレート
